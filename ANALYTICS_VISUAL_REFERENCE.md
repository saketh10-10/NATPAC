## 🎨 Color Coding

### Stat Cards
```
Total Listings:    Blue → Cyan gradient
Total Views:       Purple → Pink gradient
Messages:          Green → Emerald gradient
Avg Rating:        Orange → Red gradient
```

### Charts
```
Daily Views:       Orange → Red gradient
Weekly Bookings:   Purple → Pink gradient
```

### Badges
```
Category Badge:    Orange background, orange border
Change Indicator:  Green background, green border
```

## 📊 Data Flow Diagram

```
Agent Dashboard
    ↓
Click "View Analytics"
    ↓
Fetch /api/agents/my-promotions
    ↓
Parse Response
    ↓
Calculate Stats:
├─ Total Listings
├─ Total Views
├─ Avg Rating
└─ Message Count
    ↓
Render Main View
├─ Overview Stats
└─ Listing Grid
    ↓
User Clicks Listing
    ↓
Render Detailed View
├─ Key Metrics
├─ Charts
├─ Detailed Stats
└─ Listing Info
    ↓
User Clicks Back
    ↓
Return to Main View
```

## 📈 Chart Specifications

### Daily Views Chart
- **Type**: Bar chart
- **Data**: 7 days of views
- **Colors**: Orange to Red gradient
- **Height**: Proportional to max value
- **Labels**: Mon-Sun

### Weekly Bookings Chart
- **Type**: Bar chart
- **Data**: 7 days of bookings
- **Colors**: Purple to Pink gradient
- **Height**: Proportional to max value
- **Labels**: Mon-Sun
